# Changelog

User-visible changes are recorded here. Version tags identify release sources;
GitHub releases contain the corresponding packages.

## Unreleased

## 1.1.0 — 2026-11-15

### Added

- Per-document scroll memory and reading progress.
- Delayed side-pane loading indicator and recoverable browser failure feedback.
- Renderer, file-integrity, and GTK/WebKit integration tests.
- AppStream metadata, contribution and security guidance, and release checksums.

### Improved

- Persistent rich preview with background conversion, bounded caching, local font
  prewarming, and deferred off-screen layout.
- Nautilus selection tracking and cleanup of retired views and handlers.
- Code-fence rendering without expensive language guessing.
- Release packaging with a shared version file and validation before publication.

### Fixed

- Atomic-save monitoring, external-edit conflict detection, and preservation of
  editor content after a failed save.
- Formatted table-of-contents headings, task lists, alerts, and literal code examples.
- Theme application, code copying, F5 reload, and previous-result search navigation.
- Source-tree and installed launch paths.
- Incomplete license text and overly broad compatibility claims in documentation.
