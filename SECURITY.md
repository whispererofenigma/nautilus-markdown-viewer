# Security

Security fixes target the latest release and the default branch. Older releases
may require upgrading; this project does not offer a long-term support policy.

For a suspected vulnerability, email the maintainer at **dastuhin.rnj@gmail.com**
with a minimal reproduction, affected version, and impact. Do not include real
credentials or confidential documents. Please avoid public disclosure of exploit
details until the maintainer has had an opportunity to investigate. No response
or remediation deadline is guaranteed.

Markdown may contain raw HTML, local file references, remote images, and equations
that load MathJax from a CDN. Treat documents from unknown sources with care.
This application is not a security sandbox or HTML sanitizer. System WebKitGTK
updates remain important independently of application updates.
