Nautilus Markdown Viewer previews and edits Markdown in a resizable GNOME Files
pane or a standalone GTK window.

This release improves rich-preview responsiveness with persistent WebKit content,
background conversion, cached documents, and reduced font and layout work. A delayed
loading animation provides feedback during slower loads. It also adds reading
progress and scroll memory, strengthens save-conflict handling and atomic-save
monitoring, and fixes rendering and keyboard behavior.

### Install or update

Download the `.deb` and `SHA256SUMS` below, then run:

```sh
sha256sum --check SHA256SUMS
sudo apt install ./nautilus-markdown-viewer_1.1.0_all.deb
nautilus -q
```

Reopen Files after quitting; existing Nautilus windows will close. If you previously
used the user installer, run its `uninstall.sh` before installing the system package
to avoid loading an older user copy.

### Compatibility and limitations

Tested on Ubuntu 24.04 / Nautilus 46.4. The side pane depends on internal Nautilus
widget structure; compatibility with other versions needs testing. MathJax and
remote images require network access. Cold rendering remains variable, especially
for large or media-heavy documents; there is no universal 100 ms guarantee.

See the README for usage and the changelog for the full list of changes.
